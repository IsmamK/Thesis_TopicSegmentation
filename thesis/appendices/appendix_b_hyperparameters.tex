\chapter{Hyperparameters and System Configuration}
\label{app:hparams}

All hyperparameters are stored in \texttt{configs/defaults.yaml} and can be
overridden per experiment using Hydra.
Every evaluation run records its exact configuration to \texttt{results/<run>/config.yaml},
ensuring full reproducibility.

\section{Hardware and wall-clock runtimes}

Experiments were run across the local Windows workstation and rented vast.ai GPU
instances. Exact CPU/RAM values varied by run; GPU-backed runs used NVIDIA
RTX-class hardware.
\begin{itemize}
  \item CPU: local Windows workstation CPU for orchestration and light tests
  \item GPU: NVIDIA RTX~5090 for transcription; NVIDIA RTX~3090 for later embedding experiments
  \item RAM: instance-dependent; no run required model-parallel execution
  \item OS: Windows 11 locally; Ubuntu Linux on GPU instances
\end{itemize}
