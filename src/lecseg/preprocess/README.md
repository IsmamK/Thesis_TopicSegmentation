# lecseg.preprocess

Audio/video preprocessing pipeline. Runs Whisper, shot detection, OCR, and prosody extraction.

## How to know you are done

- [ ] All public functions have a one-line docstring.
- [ ] Module is importable: `python -c "from lecseg.preprocess import *"` exits with no error.
- [ ] Unit tests live in `tests/test_preprocess.py`.
