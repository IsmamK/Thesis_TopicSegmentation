# Defense poster (A1 portrait)

Built in **T40**.

## Build

```
make poster
# or
cd poster && pdflatex poster.tex
```

Output: `poster/poster.pdf` (single page, A1 portrait).

## Print at A1

A1 is **594 × 841 mm** (about 23.4 × 33.1 inches). Most BRAC print services
accept A1 PDFs. Confirm 300+ DPI for any raster images you embed.

## Layout philosophy

Read order is left → right, top → bottom. Sections in this template:
1. Why & contributions
2. Pipeline diagram (full width — the visual anchor)
3. Main results & ablations side by side
4. Take-aways
5. Resource links footer
